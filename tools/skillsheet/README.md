# スキルシート生成ツール（ローカル専用・私用）

サイトの「経歴」ページ（`/profile/`）に掲載中の案件（`assets/data.js` の
`window.PROJECTS`）をチェックで選び、**個人の履歴書フォルダにある実テンプレート
（`スキルシート_AKIRA.xlsx`、実際の会社名など未公開の情報を含む）** に書き込んで
書き出すための、本人専用ローカルツールです。

公開サイトの「経歴」ページから案件を選んでスキルシートを書き出せる機能は、
これとは別に `/skillsheet/`（リポジトリ直下、`skillsheet/`）として実装されています。
そちらは完全にブラウザ内で動作し、サニタイズ済みテンプレート（`skillsheet/template.xlsx`、
案件テーブルは空欄）と公開データのみを使うため、サーバーもこのローカルツールも不要です。
このローカルツールは、実際の応募で「本当の」テンプレートから出したい場合にのみ使います。

- **公開サイトには含まれません。** Web UI はローカルの Node サーバーとしてのみ動作します
  （テンプレートが個人の履歴書フォルダにあり、xlsx を書き換える処理はサーバーサイド実行が必要です）。
- **個人情報欄（氏名・GitHub ID・得意分野・自己PRなど、テンプレート1〜15行目）には触れません。**
  テンプレート側の値がそのまま使われます。書き換えるのは17行目以降の案件経験テーブル（最大16件）のみです。
- **案件データはここでは編集できません。** 単一データソースは `assets/data.js` のままです。
  内容を直したい・案件を増やしたい場合は `assets/data.js` の `window.PROJECTS` を編集してください
  （サイト本体にも反映されます）。このツールでできるのは、掲載中の案件から出力対象をチェックで選び、
  並び順（テンプレートの何件目に入れるか）を上下ボタンで調整することだけです。
- **選ばなかった案件ブロックは非表示行にします。** 16件分の枠のうち使わなかった行は、
  値を消すだけでなく行そのものを隠すため、罫線や塗りなどのデザインが空欄のまま出力に残りません。
- **xlsx の読み書きに ExcelJS を使いません。** このテンプレート（LibreOffice 由来・inlineStr・
  スタイル数が多い）は、ExcelJS で読み込んで書き戻すだけで（何も変更しなくても）Excel が
  「修復」を要求するファイルになってしまう既知の問題があるため、`lib/xlsxPatch.js` で
  `xl/worksheets/sheet1.xml` だけを文字列レベルで書き換えている。styles.xml・workbook.xml・
  theme 等は一切触らず、元のバイト列のまま zip に戻す。この代わりに、空欄セルの罫線を
  消す機能（旧バージョンにあった）は現状実装していない。
- **年齢・スキル年数は生成のたびに `assets/data.js` から再計算します。** 年齢は
  `config.json` の `birthDate` から生成日時点の満年齢を算出（未設定ならテンプレートの値のまま）。
  実務開発経験のスキル年数（10〜15行目）は `window.SKILLS` の `years` を経験年数の多い順に反映します
  （各カテゴリの行数を超える分は、経験年数が少ないものから切り捨てられます）。

## セットアップ（初回のみ）

```bash
cd tools/skillsheet
npm install
cp config.example.json config.json   # 既に config.json があれば不要
```

`config.json` の `templatePath` を、実際のテンプレート xlsx への絶対パスに書き換えてください
（デフォルトでは `~/Documents/個人/履歴書・職務経歴書/スキルシート_AKIRA.xlsx` を指しています）。
年齢を自動更新したい場合は `birthDate`（`"YYYY-MM-DD"`）も設定してください。未設定でも動作しますが、
その場合は年齢セル（Y3）はテンプレートの値のまま変更されません。
`config.json` は個人情報を含むため `.gitignore` 対象です。

## 使い方

```bash
cd tools/skillsheet
npm start
```

`http://localhost:4173` を開く（または「経歴」ページのリンクから新規タブで開く）と、
サイト掲載中の案件一覧が表示されます。出力したい案件だけチェックし、必要なら並び順を
調整して「スキルシートを書き出す」を押すと、`output/`（`.gitignore` 対象）にファイルが
保存され、同時にブラウザからダウンロードされます。

## `window.PROJECTS` からテンプレート列への変換

`lib/siteProjects.js` が変換を行います。

| テンプレート列 | 由来 |
|---|---|
| 業種 | `industry` |
| 会社名・団体名 | `org.name` |
| 雇用形態・役割 | `role` |
| 規模・人数 | `team` / `sub` |
| 使用言語・FW／DB／サーバ・OS／ツール | `stack`（既知の技術名リストで自動分類。未知の技術名は「ツール」欄に入る） |
| 開始日／終了日 | `start` / `end`（`end` が空＝継続中） |
| 案件名 | `domain`（無ければ `service`） |
| 業務内容 | `body`（箇条書きに変換） |
| 担当領域（6フラグ） | `phases` |

`stack` の分類先を変えたい、または新しい技術名を追加したい場合は
`lib/siteProjects.js` の `LANG_FW` / `DB` / `SERVER_OS` / `TOOLS` を編集してください。
